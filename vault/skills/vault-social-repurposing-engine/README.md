# Social Repurposing Engine

## What it does

Takes any piece of source content — a blog post, article, email, transcript, or bullet-point list — and produces a complete, platform-native social media package in one pass. No reformatting required. Everything is written for its specific channel from scratch.

## Why it's better than a plain LLM prompt

A generic prompt produces generic outputs. This skill is built around the specific format constraints, audience expectations, and tonal norms of each platform. It enforces a structured five-section output every time, so you always get a complete package rather than a partial response. The key message summary step also forces a distillation pass that improves quality across all downstream outputs.

## Inputs

Paste in any of the following:
- A full blog post or article
- An email or newsletter
- A video or podcast transcript
- A bullet list of key points or talking points
- A product announcement or press release

## Outputs

1. **Key Message Summary** — 3-5 core ideas as bullet points
2. **LinkedIn Post** — 150-300 words, hook-driven, professional-human tone
3. **X/Twitter Thread** — 5-7 numbered tweets, hook + expansion + CTA
4. **Instagram Caption** — 100-150 words + 15-20 hashtags
5. **Short-Form Video Script** — Hook/Body/Close for a 45-60 second video with director notes

## Permissions used

None. This skill operates entirely on the text you provide.

## Memory behavior

No memory read or write. Each session is stateless.

## Ideal use cases

- Repurposing a weekly blog post into a full week of social content
- Turning a product launch email into multi-channel social coverage
- Converting a podcast transcript into shareable content assets
- Giving a content team a ready-to-publish starting point across all platforms
