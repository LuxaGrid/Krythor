# Rewrite Optimizer

## What it does

Takes any piece of text — an email, paragraph, bio, sales page section, social post, proposal, or any written content — along with a target goal, and produces a diagnosed primary rewrite, a detailed change log explaining every edit, a readability comparison, and two alternative rewrites with different stylistic approaches.

## Why it's better than a plain LLM prompt

"Rewrite this to be clearer" produces one output with no explanation. This skill runs a diagnostic before touching a word, so the user understands what was wrong. The change log turns every rewrite into a learning opportunity — you see exactly what changed and why, which makes the next draft better before it even reaches the optimizer. The readability comparison gives objective metrics. The two alternative versions mean you always have a range of choices, not a take-it-or-leave-it single output.

## Inputs

Provide two things:
- **The text** — any length, any format. Paste the full piece.
- **The target goal** — choose one or describe your own:
  - Clearer
  - Shorter
  - More persuasive
  - More professional
  - More emotional / human
  - More direct
  - Custom: describe what you need (e.g., "less jargon for a non-technical audience")

## Outputs

1. **Diagnosis** — 4-6 specific weaknesses identified in the original text
2. **Primary Rewrite** — full rewritten version targeting the stated goal
3. **Change Log** — numbered list of every significant change with before/after quotes and reasoning
4. **Readability Comparison** — grade level, sentence length, word count, passive voice count, and clarity rating for original vs. rewrite
5. **Alternative Versions** — two additional rewrites with named stylistic approaches

## Permissions used

None. Operates entirely on the text provided.

## Memory behavior

No memory read or write. Each session is fully stateless.

## Ideal use cases

- Polishing a sales email or proposal before sending
- Tightening a bio, about page, or LinkedIn summary
- Making a complex or jargon-heavy document accessible
- Strengthening an argument or pitch before a presentation
- Learning to write better by studying the change log over time
